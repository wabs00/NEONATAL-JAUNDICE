WORKFLOW GUIDE

Clarity at every step.

A practical guide to this workspace.

1. Create an assessment

Use a baby record ID, enter age, weight, gestational age and feeding type, then attach a photo you have permission to store. Save to create a pending review record.

2. Document the review

Open a record to view the photo, add notes, and enter a measured bilirubin value in mg/dL if available. Set the status to Reviewed or Referred to reflect a decision made by your clinical team.

3. Follow up and export

Search records by baby ID, filter by status and export your filtered records as CSV. Exported files contain sensitive information; store them according to your facility’s policy.

What AI means in this version

The original project generated random diagnoses. Those results have been removed. Research mode provides experimental comparisons with the dataset’s class labels. The model has not been clinically validated. Clinical review and measured bilirubin remain separate from research results.
